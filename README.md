# 🧠 Microprocessor Lab & Assignments

A collection of microprocessor lab assignments, homework exercises, and course projects completed as part of a university Microprocessor Laboratory course. This repository demonstrates practical implementation of microprocessor concepts using programming and hardware/simulation tools.

---

## 📌 About This Repository

This repository contains structured lab sessions, homework problems, and major projects developed throughout the semester. The work focuses on understanding:

* Instruction sets and Assembly programming
* Data transfer and arithmetic operations
* Control flow and branching
* Interrupt handling
* Input/Output interfacing
* Practical embedded system design

Each folder represents a separate lab session, homework task, or project.

## ▶️ How to Use This Repository

### 1️⃣ Clone the repository

```
git clone https://github.com/ParsaHaghighatgoo/Micro-Lab-Assignments.git
```

### 2️⃣ Navigate to a specific assignment

```
cd HW2Q1
```

### 3️⃣ Open the project

* Open source files in your IDE or simulator.
* Configure the correct microprocessor target.

### 4️⃣ Build / Assemble

* Compile C/C++ files using the required compiler.
* Assemble Assembly files using the appropriate assembler.

### 5️⃣ Run or Simulate

* Run inside simulator
* OR upload to hardware board (if required)
